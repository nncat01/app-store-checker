# App Store Checker
Автоматически обновляемый список приложений из App Store (в основном российских) в виде **`.csv`** таблицы, который содержит:
- Название в App Store 
- App ID
- Bundle ID
- Актуальную версию
- Аккаунт разработчика
- Доступность в 30 ключевых регионах

## Применение
- Восстановление удалённых из App Store приложений при помощи ipatool, asspp, imazing, IPA_Downloader и тд
- Отслеживание доступности приложения в разных регионах

## Список регионов, в которых выполняется проверка
Список ограничен 30 регионами, так как полная проверка заняла бы слишком много времени

Россия, Турция, Индия, США, Казахстан - основные регионы, которыми пользуются российские пользователи
Армения, Азербайджан, Беларусь, Киргизия, Таджикистан, Туркмения, Украина, Узбекистан, Грузия - страны СНГ
Германия, Эстония, Франция, Италия, Литва, Латвия, Польша - страны ЕС
Гонконг, Китай, Тайвань - Китай
Бразилия, Канада, Грузия, Израиль, Япония, ЮАР - остальные

## Структура
- **`links.txt`** — источник App ID для поиска приложений в App Store
- **`update_apps.py`** — скрипт, который читает `links.txt`, запрашивает
  данные через открытый iTunes Lookup API и пишет/обновляет `apps.csv`
- **`apps.csv`** — список приложений
